# Hanze Li's Portfolio

Source for [maotechh.github.io](https://maotechh.github.io/), a static portfolio for my embedded systems research and engineering work.

The site is intentionally dependency-free. Open `index.html` directly or serve the repository with any static HTTP server.

## Local preview

```bash
python3 -m http.server 4173
```

## Structure

- `index.html`: content and semantic structure
- `styles.css`: responsive layout and visual design
- `script.js`: mobile navigation and small progressive enhancements
- `assets/images`: project and profile imagery
- `assets/docs`: downloadable English and Chinese resumes
